# ☁️ [Web v15] 다문화 도서관 납품/구입 전문 플랫폼 기획서
## (3D Cloud Airship & Sky Islands Library)

> **"Bruno Simon 3D 탐험 스타일: 3D 스팀펑크 비행선을 조종하여 하늘 섬 도서관들을 비행하는 수서 몰"**

---

## 1. 개요 & 3D 주행/비행 인터랙션 (Bruno Simon Style)

* **핵심 컨셉:** 사용자가 **3D 스팀펑크 비행선(Airship)**을 비행 조종하여 구름 위 부유하는 세계 문화 하늘 섬(Sky Islands)을 탐험.
* **공간 디자인 4대 파트 (Concept Images 4장 반영):**
  1. **스팀펑크 메인 비행선:** 하늘 위를 부유하며 도서를 수집하는 주행 기지.
  2. **아시아 문화 구름 섬 (Asian Cloud Island):** 벚꽃과 등불 아래 피어나는 동양 전래동화 관.
  3. **유럽 성 구름 섬 (European Castle Island):** 고대 성곽 위 떠다니는 중세 고전 문학 관.
  4. **사서 관제 스카이포트 (Sky Port Control):** 비행선이 싣고 온 도서들을 장바구니/공문 견적서로 처리.

---

## 2. 5개 필수 페이지 구성 (5 Key Pages)

1. **메인 페이지 (`#home`):**
   * **Three.js 메인 배너 & 3D 비행:** 3D 구름 맵 + 방향키로 비행선 조종.
   * **3D 하늘 섬 기획전관:** 각 문화 섬에 착륙/접근 시 기획전 팝업.
   * **신간 목록:** 사서 전용 리스트 + 3D 부유 카드 믹스.
2. **도서 검색 & 수서 페이지 (`#search`):**
   * 다국어, 연령, ISBN, KDC 코드, 출판사 실시간 필터.
3. **큐레이션 기획전 관 (`#curation`):**
   * "구름 위 세계 전래동화전", "유럽/아시아 아동 명작전" 3D 기획전.
4. **장바구니 & 공문 견적함 (`#cart`):**
   * 기관 할인 적용 + **1클릭 스카이포트 공문 견적서(PDF/인쇄) 자동 발급**.
5. **도서 상세 & 서지정보 관 (`#detail`):**
   * **360도 Three.js 3D 양장본 도서 회전**, 오디오 낭독 재생.

---

## 3. 사서 맞춤 인터랙션 & 버튼 클릭 효과

* **인터랙션 연출:**
  * 클릭 시 비행선 프로펠러 바람 소리(Web Audio) 및 구름 링 확산 효과.
