# 🏘️ [Web vc01] 다문화 도서관 납품/구입 전문 플랫폼 기획서
## (Tiny Town Book Village · 타이니 타운 책 마을)

> **"작은 픽셀 마을의 집집마다 한 나라의 책이 살고, 아이는 책 수레를 끌고 집을 찾아가고, 사서는 책가방에서 공문 견적을 뽑는다"**

* 구현 폴더: `web/vc01/` (통합 뷰어 `web/index.html` 드롭다운 → vc01)
* 2D 에셋: **Kenney · Tiny Town 1.1** (https://kenney.nl/assets/tiny-town) — CC0, 16px 타일 132종(12×11 시트) → `web/vc01/assets/tiles/tilemap_packed.png` (`assets/LICENSE_Kenney_CC0.txt`)
* 공통 디자인 방향: [`web_v17_v19_design_brief.md`](./web_v17_v19_design_brief.md)
* 시리즈 표기: `vc` = *character/tile 기반 2.5D* 시리즈의 첫 번째(01). v20(3D GLB) 계열과 구분.

## 1. 기획 배경과 문제 정의

| 관찰 | 기획 대응 |
|---|---|
| v20의 3D 던전은 "탐험"은 좋았지만 **어두운 톤**이 도서관 사서의 첫인상 신뢰와 어린이 정서에 부담이 될 수 있다. | **밝은 낮의 목가적 픽셀 마을**로 전환. 초록 들판·파란 하늘·크림 종이. 라이트 모드. |
| Tiny Town은 **2D 16px 타일셋**이고 캐릭터 스프라이트가 없다(샘플 이미지의 주민은 별도 팩). | 타일을 Three.js **스프라이트(항상 카메라를 향하는 판)** 로 세워 2.5D "종이 인형극 무대"로 연출. 플레이어는 3D로 만든 **책 수레(Book Wagon)** 로 대체. |
| 다문화 = 여러 나라 = 여러 집. 은유가 직관적이어야 한다. | **집 1채 = 언어권 1개**. 집 위에 그 나라 책이 떠 있고, 수레를 끌고 집 앞에 가면 책이 솟아오른다. |
| 픽셀 아트가 UI까지 침범하면 저가 게임처럼 보인다. | 픽셀은 **3D 무대·로고 마크·배지에만**. 카드·검색·견적함은 세리프 헤드라인 + 정갈한 표로 사서 신뢰 유지. |

**한 줄 컨셉:** *동화책 지도 같은 픽셀 마을 × 집집마다 다른 나라의 책 × 사서를 위한 수서 데스크.*

## 2. 에셋 분석 (Tiny Town 타일 인덱스 맵)

시트 규격: 16px × 16px, 12열 × 11행, `index = row*12 + col`. 텍스처는 `NearestFilter`로 픽셀 선명도 유지, 서브-UV(`repeat 1/12 × 1/11`, `offset`)로 타일 1장씩 참조.

| 분류 | 인덱스 | 사이트 내 역할 |
|---|---|---|
| 잔디 | 0, 1, 2(꽃) | 바닥(평면 메시). 의사난수 배치로 자연스러운 변주 |
| 흙길 | 12~14 / 24~26 / 36~38 (모서리·가장자리), 25·40~42(중앙), 43(디딤돌) | 마을 큰길(2줄), 집으로 오르는 디딤돌, 광장·숲길 |
| 나무·풀 | 3·15·27(주황 침엽), 4·16·28(초록 침엽), 5(둥근 관목), 17(새싹), 29(버섯) | 마을 외곽·숲길 양옆, 장식 |
| 집(회색 지붕·갈색 벽) | 지붕 48·49·50 / 60·61·62, 벽 72~75·84~87(문·창) | 집 패턴 A(3폭)·C(2폭) |
| 집(주황 지붕·회색 벽) | 지붕 52·53·54 / 64·65·66, 벽 76~79·88~91 | 집 패턴 B(3폭)·D(2폭) |
| 울타리·표지 | 44~47·56·58·59·68~71·80~82(울타리), 83(이정표), 57(게시판) | 장터 가판, 숲길 이정표, 마당 경계 |
| 성 | 96~102·108~110·120~126(성벽·창), 111~114(아치), 103(성문), 123·124(기둥) | 마을 끝 성(히어로), 성 도서관 전시실 배경 |
| 소품 | 93(코인), 94(벌통), 104(우물), 106·107(항아리), 115~131(도구) | 코인 부유, 광장 우물, 장식 |

## 4. 정보 구조 & 5개 페이지

```
#home ─ 히어로(걷는 픽셀 마을) → 마을 곳곳 기획전(3D) → 신간(리스트 ↔ 마을 길 책 수레 3D) → 사서 스트립
#search ─ 언어·연령·KDC·출판사·가격 필터 + 카드(ISBN·KDC 상시)
#curation ─ 광장 장터 / 성 도서관 / 숲속 독서 길 (3D) + 패키지 일괄 담기
#cart ─ 책가방 · 공문 견적함(납품가 -10%, 기관 정보, 인쇄/PDF, 엑셀)
#detail/:id ─ 마을 우물 위 360° 책 + 서지 스펙 + 관련 도서
```

### 4-1. 히어로 — 걷는 픽셀 마을 (18×11 타일, 1타일 = 2 world unit)
* 바닥: 잔디 + 가로 큰길 2줄(13/37 가장자리, 40/42 변주) + 집으로 가는 디딤돌(43).
* **집 8채 = 8개 언어권**(VI·ZH·RU·JA·EN·TL·MN·TH): 큰길 위쪽 5채, 아래쪽 3채. 각 집 지붕 위에 해당 언어 책이 부유·회전.
* 마을 끝 성(3×3), 이정표 2, 우물, 벌통, 항아리, 울타리 2열, 외곽 나무 줄, 버섯·새싹, 코인 5개(부유).
* **플레이어 = 책 수레**(3D: 몸통·바퀴 4·손잡이·책 2권). WASD/방향키 이동, 이동 시 덜컹 애니메이션. 집 중심 2.6타일 이내 접근 → 책이 1.2유닛 솟아오르고 1.25배 확대·빠른 회전. 클릭 → 상세.
* 카메라: 수레를 60% 가중으로 따라가는 45° 상공 시점 + 마우스 패럴랙스. 스프라이트는 카메라를 향해 자동 정렬되어 종이 인형극처럼 보임. 스프라이트 아래에 원형 그림자 패치.

### 4-2. 마을 곳곳 기획전 (Exhibition Engine)
| 장소 | 진열 | 배경 | 수록 |
|---|---|---|---|
| 마을 광장 장터 | 우물 중심 반지름 5.2타일 원형 가판(울타리+이정표) 위 책 부유 | 흙 광장 + 디딤돌 링 + 외곽 나무 14 | 세계 전래동화 9권 |
| 성 도서관 | 11폭 성벽(창·아치·성문) 앞 2줄 부유 | 성 앞 길, 모서리 나무 | 청소년 세계문학 7권 |
| 숲속 독서 길 | S자 오솔길 이정표마다 책 | 빽빽한 침엽수, 버섯 | 이중언어 그림책 6권 |
* 드래그 회전(성 도서관은 ±20° 스윙만), 호버 툴팁, 클릭 상세. 홈·큐레이션 공용 엔진.

### 4-3. 신간 — 마을 길 책 수레 3D
* 19타일 길이의 마을 길 위로 신간 8권이 통통 튀며 지나가고, 길 양옆 나무·이정표·우물.

### 4-4. 책가방 · 공문 견적함 / 4-5. 상세
* v17~v20과 동일한 사서 기능(4개 스탯, 기관 정보, 인쇄/PDF, 엑셀). 상세는 우물 옆 작은 마당에서 책이 360° 회전.

## 6. 기술 구성
* Three.js r128. `TextureLoader`로 시트 1장 로드 → `Texture.clone()` + `repeat/offset` 서브-UV로 타일 텍스처 캐시(132종 지연 생성). `NearestFilter`, `generateMipmaps=false`, `sRGBEncoding`.
* 바닥: `PlaneGeometry` + `MeshStandardMaterial(map)`, 그림자 수신. 세움 요소: `THREE.Sprite` + `SpriteMaterial(alphaTest .4)` → 카메라 정면 정렬. 그림자는 원형 반투명 패치.
* 로드 완료(`ready`) 후 씬 빌드 및 전시실 `refresh()`; 로드 전에는 책만 렌더.
* 표지는 Canvas 절차 생성, 상태는 `localStorage`(`mlmc01_*`), 엑셀 SheetJS, 공문 인쇄 `@media print`.
